# Security and responsible disclosure

## Reporting a vulnerability in CivicProbe
Please open a private security advisory on GitHub (Security → Advisories → Report a vulnerability) rather than a public issue.

## Findings about third-party services
CivicProbe may surface candidate discrepancies in public calculators or government services. These are
**private findings** until verified by a human and disclosed responsibly to the service owner first. See
[docs/responsible-testing.md](docs/responsible-testing.md) and [docs/reporting-language.md](docs/reporting-language.md).
Do not publish live findings in issues or pull requests.
